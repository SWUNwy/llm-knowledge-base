# R002 - KnowledgeBase 官网

## 背景

KnowledgeBase 是一个本地优先的 AI 知识库产品，即将进入商业化运营阶段。当前缺少一个完整的官网来承载产品展示、用户转化和品牌传达。

## 目标

1. **产品展示**：清晰传达"AI 知识库"的核心价值，让用户 3 秒内理解产品
2. **用户转化**：通过免费试用 CTA 推动注册转化
3. **品牌传达**：建立"专业可信 + 科技先锋"的品牌形象
4. **商业化支撑**：三档定价展示，支持订阅决策

## 目标用户

| 用户类型 | 典型场景 |
|----------|----------|
| 研究者/学生 | 学术研究、论文笔记、知识管理 |
| 知识工作者/开发者 | 技术文档、学习资料整理 |
| 企业团队 | 内部知识库、团队协作文档 |
| 终身学习者 | 通用的个人知识管理 |

## 商业模式

- 纯订阅制（月付/年付）
- 14 天免费试用，无需信用卡
- 三档定价：个人版 / 专业版 / 团队版

## 范围

### 包含（Phase 1 - MVP）

- 单页长滚动首页（7 个模块）
- 登录/注册入口
- 响应式适配（桌面优先，兼顾移动端）
- 基础 SEO（meta、OG、结构化数据）
- 性能优化（Lighthouse > 90）

### 包含（Phase 2 - 内容扩展）

- 独立定价页 /pricing
- 文档中心 /docs（7 个文档模块）
- 博客系统 /blog

### 不包含

- API 参考文档
- 后台管理系统
- 多语言支持（Phase 3）
- 支付系统集成（独立需求）
