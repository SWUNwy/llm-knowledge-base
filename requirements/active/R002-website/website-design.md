## 1. 概述

为 LLM Knowledge Base 产品设计商业化官网。产品定位：本地优先的 AI 知识库，自动将零散资料编译成结构化 Obsidian 知识库。

### 核心决策

| 维度 | 决策 |
|------|------|
| 目标用户 | 全覆盖：研究者、知识工作者、企业团队、终身学习者 |
| 商业模式 | 纯订阅制 + 14 天免费试用 |
| 品牌调性 | 专业可信 + 科技先锋（混合） |
| 建设策略 | 渐进式：Phase 1 单页长滚动，Phase 2 拆分多页 |

## 5. 首页模块详细设计

### 整体节奏

```
深(Hero) → 浅(痛点) → 浅灰(功能) → 深(流程) → 白(定价) → 深(CTA+Footer)
```

### 5.1 Navbar（固定顶部）

- 左侧：Logo（渐变方块 + "KnowledgeBase"）
- 中间：锚点导航（功能 / 流程 / 定价 / 文档）
- 右侧：渐变色"免费试用"按钮
- 滚动后添加半透明背景 + 模糊效果

### 5.2 Hero（深色背景）

- 标签：`AI 驱动 · 本地优先 · Obsidian 兼容`
- 主标题：**你的私有 AI 知识库**
- 副标题：自动将零散资料编译成结构化知识，用 AI 驱动问答和持续增强
- 双按钮：`免费试用 14 天`（渐变主按钮） + `观看演示 ▶`（描边按钮）
- 流程动画：资料来源（网页/PDF/视频）→ AI 编译（圆形光晕）→ 知识库输出（带 Wiki 链接的卡片）

### 5.3 痛点共鸣（白色背景）

- 标题：**资料越来越多，但真正要用时...**
- 3 个红色卡片：
  - 🔍 找不到 — 存的资料不知道在哪，关键词搜不到
  - 🧩 没关联 — 知识点是孤岛，没有形成网络
  - 📖 难理解 — 论文/长文档太多，消化不完
- 底部蓝色渐变过渡带：KnowledgeBase 用 AI 自动整理资料，生成结构化知识库

### 5.4 核心功能区（浅灰背景）

- 标签：`三大核心能力`
- 标题：**一站式知识管理**
- 3 个功能卡片（白底 + 阴影）：
  - 📥 **智能导入**（蓝色图标）— 一键导入网页、PDF、视频、GitHub 仓库
  - 🤖 **AI 编译**（紫色图标）— 自动生成 Wiki 文章，提取概念，建立双向链接
  - 💬 **智能问答**（绿色图标）— 对知识库提问，AI 基于你的资料回答，答案可沉淀回库
- 每个卡片底部有"了解更多"链接

### 5.5 使用流程（深色背景）

- 标签：`三步开始`
- 标题：**从资料到知识，只需要三步**
- 3 步卡片（深色底 + 对应色边框）：
  - ① 导入资料（蓝色编号）— 粘贴 URL、上传 PDF、收藏视频
  - ② AI 自动编译（紫色编号）— 提取概念、生成 Wiki、建立链接
  - ③ 提问与沉淀（绿色编号）— 对知识库提问，答案沉淀回库

### 5.6 定价区（白色背景）

- 标题：**选择适合你的方案**
- 副标题：14 天免费试用，无需信用卡
- 三档定价卡片：

| | 个人版 | 专业版 | 团队版 |
|---|--------|--------|--------|
| 价格 | ¥49/月 | ¥99/月 | ¥299/月 |
| 年付 | ¥468/年（省¥120） | ¥948/年（省¥240） | ¥2868/年（省¥720） |
| 图标色 | 蓝色 | 紫色（渐变背景+推荐标签） | 绿色 |
| 功能 | 无限导入、基础编译50次/月、全文检索、Obsidian同步 | 无限导入、无限编译、高级AI模型、语义检索、优先支持 | 全部功能、5人协作、共享知识库、管理后台、专属客户经理 |
| CTA | 蓝色描边按钮 | 白底按钮（最醒目） | 绿色描边按钮 |

- 专业版卡片微微放大（scale 1.03）+ 渐变背景 + "最受欢迎"标签

### 5.7 底部 CTA + Footer（深色背景）

**CTA 区**：
- 深蓝→深紫渐变背景
- 标题：**开始构建你的 AI 知识库**
- 副标题：14 天免费试用，无需信用卡。从今天开始，让零散资料变成结构化知识。
- 单一按钮：`免费试用 14 天`
- 信任标签：无需信用卡 · 随时取消 · 支持多模型

**Footer**：
- 四列布局：品牌介绍 / 产品（功能、定价、更新日志、路线图）/ 资源（文档、博客、常见问题、社区）/ 关于（关于我们、联系方式、隐私政策、服务条款）
- 底部：版权信息 + 社交链接（GitHub、Twitter/X、微信）

## 8. 技术实现建议

### 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Next.js（SSG 静态生成，SEO 友好） |
| 样式 | TailwindCSS |
| 动画 | Framer Motion（滚动触发、流程动画） |
| 部署 | Vercel / Cloudflare Pages |
| 分析 | Plausible / Umami（隐私友好） |

### 性能目标

| 指标 | 目标 |
|------|------|
| LCP | < 2.5s |
| FID | < 100ms |
| CLS | < 0.1 |
| Lighthouse | > 90 |

### SEO 基础

- 每个页面独立 meta title/description
- Open Graph 图片
- 结构化数据（Product, FAQ）
- sitemap.xml
- robots.txt

## 9. Phase 路线图
