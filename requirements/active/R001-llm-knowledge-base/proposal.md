# R001 - LLM Knowledge Base

## 背景

研究者和知识工作者日常会收集大量零散资料（网页、PDF、视频、代码），但这些资料往往散落在各处，难以形成结构化知识。现有的知识管理工具（如 Obsidian、Notion）需要大量手动整理工作，且缺乏智能问答能力。

本项目旨在构建一个本地运行的 Web 应用，自动将零散资料编译成结构化的 Obsidian 知识库，并用 LLM 驱动问答和持续增强。

## 目标

1. **智能导入**：支持 URL、PDF、视频、代码等多种来源的一键导入
2. **自动编译**：LLM 自动生成带双向链接的 Wiki 文章
3. **智能问答**：对知识库提问，答案可沉淀回库
4. **本地优先**：所有数据在用户的 Obsidian vault 中，完全掌控

## 范围

### 包含 (MVP - Phase 1)

- URL/PDF/视频/GitHub 仓库导入
- 原始文档 → Wiki 文章编译
- 基于知识库的问答
- SQLite 全文搜索
- 多 LLM 提供商支持（Gemini/Claude/GPT/本地）
- 用户名密码认证
- 基础 Web UI（导入/文库/问答/设置）

### 不包含 (Phase 2)

- 向量语义检索（Phase 1 仅关键词搜索）
- 知识图谱可视化
- 多格式输出（幻灯片/报告）
- CLI 支持
- 大规模优化（5000+ 文档）

## 关键决策记录

| 决策项 | 选择 | 理由 |
|--------|------|------|
| API 认证 | 用户名密码 | 本地应用安全需求 |
| 编译模式 | 混合（小批量同步，大批量异步） | 平衡响应与复杂度 |
| 问答输出 | 可配置流式 | 灵活适配场景 |
| 文件上传 | 本地路径 | 本地应用，无需上传 |
| API 版本 | `/api/v1/` | 便于未来迭代 |
| 向量存储 | SQLite-vec | 轻量级，无需额外服务 |
| LLM 重试 | 自动重试（3次，指数退避） | 提高可靠性 |
| 导入失败处理 | 智能重试 + 跳过 | 网络重试，格式跳过 |
| 编译失败处理 | 部分成功 | 保留成功的，记录失败的 |
| 大文件处理 | 分块处理 | 降低内存压力 |
| 并发控制 | 有限并发（最多 N 个） | 资源可控 |
| 测试框架 | Playwright (E2E) | 跨浏览器支持好 |
| LLM 测试 | VCR 录制回放 | 零成本、确定性 |
| 测试数据 | 混合（小文件内置 + 大文件脚本生成） | 平衡仓库大小与真实性 |
